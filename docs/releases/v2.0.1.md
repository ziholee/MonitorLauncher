# Monitor Launcher v2.0.1

워크스페이스 복원 정확성과 저장·실행 UI의 안전성을 개선한 패치 버전입니다.

## 변경 사항

- 같은 복원 작업에서 이미 사용한 창을 다시 선택하지 않습니다. 프로세스명과 저장된 실행 파일 경로를 확인하고 제목이 같은 창을 우선 선택합니다.
- 모니터 사이 빈 공간도 화면 밖으로 판단합니다. 제목 영역에 접근하기 어렵거나 크기가 비정상인 창을 주 모니터로 복구합니다.
- 현재 모니터의 작업 영역에 맞춰 복원 크기와 위치를 제한합니다.
- 창 이동 API가 실패하면 복원 성공으로 집계하지 않으며, 저장된 모니터가 없어 주 모니터로 대체한 결과를 안내합니다.
- 파일 탐색기와 Windows Terminal을 캡처 대상에 포함하고 바탕화면·작업 표시줄 창은 제외합니다.
- 복원 중 트레이 메뉴를 비활성화하고 중복 복원 요청을 차단합니다.
- 같은 이름의 워크스페이스를 저장할 때 덮어쓰기를 확인하고, 저장 후 해당 항목을 선택합니다.
- 창 크기 조절·최대화·스크롤을 지원합니다. 버튼명을 실제 동작에 맞춰 '화면 밖 창 복구'로 변경합니다.

## 호환성과 제한

기존 프로필 및 워크스페이스 JSON 형식은 유지합니다. 제목이 같거나 변경된 창은 정확한 대응을 보장하지 않습니다. 앱의 단일 인스턴스 정책으로 새 창이 생성되지 않으면 부족한 창은 복원 실패로 표시될 수 있습니다.

## 검증 상태

- 정적 변경 검사: `git diff --check` 통과.
- 현재 개발 환경에는 `dotnet`이 없어 빌드 및 Windows 실행 검증은 수행하지 못했습니다.
- 배포 전 [Windows 회귀 검증 절차](../workspace-regression.md)에 따라 단일 앱 실행, 다중 창 복원, 모니터 분리, 트레이 중복 실행 차단 및 작은 화면 UI를 확인해야 합니다.
